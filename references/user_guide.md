# Serenity 卡脖子框架 · 使用指南（A股/港股/美股）

## 如何触发本技能

直接说以下任意表达即可：

- "用 serenity-stock-choke 分析 [板块名]"
- "分析 [产业链] 的卡脖子机会"
- "找 [赛道] 的瓶颈环节"
- "这个板块有哪些卡脖子的公司"
- "帮我用 Serenity 框架分析 [板块]"

## 分析示例

### 示例1：电力板块

```
用户：分析电力板块
→ Serenity框架分析步骤：
  1. 定位周期：需求爆发期（夏季用电高峰+AI算力需求）
  2. 溯源供应链：煤炭→火电/水电→电网输配→用户
     → 卡脖子节点：特高压输电设备、电网调度系统
  3. 找标的：国电南瑞(600406)、特变电工(600089)、华能国际(600011)
  4. 四维信号验证
  5. 多空确认
  6. 输出报告
```

### 示例2：光模块/CPO板块

```
用户：分析CPO板块
→ Serenity框架分析步骤：
  1. 定位周期：技术跃迁期（CPO替代可插拔光模块）
  2. 溯源供应链：光芯片→光器件→光模块→交换机→数据中心
     → 卡脖子节点：EAM/EA-VCSEL激光器、MPO连接器
  3. 找标的：源杰科技(688498)、炬光科技(688167)、三安光电(600703)
  4. 四维信号验证
  5. 多空确认
  6. 输出报告
```

## 六步法速查卡

| 步骤 | 问题 | 回答 |
|------|------|------|
| 1 | 这个板块现在处于什么周期？ | 需求爆发/技术跃迁/供给受限 |
| 2 | 供应链的瓶颈在哪一层？ | [具体环节] |
| 3 | 哪几家公司在这个瓶颈上？（A股/港股/美股） | [名单] |
| 4 | 哪些是真正的瓶颈，哪些是伪概念？ | 应用排除规则 |
| 5 | 多空信号是什么？ | 做多3-5条 vs 做空2-3条 |
| 6 | 今天资金面怎么样？ | 主力净流入/北向/融资余额 |

## 数据查询快捷指令

> 按三级策略降级使用：智能体自带财经工具 → 本技能脚本 → 网络检索。
> 脚本位置：`scripts/a_stock_query.py`，零依赖，无需 API Key。

### 内置脚本命令

```bash
python3 scripts/a_stock_query.py search [关键词]    # 名称联想（个股+板块代码）
python3 scripts/a_stock_query.py stock [名称/代码]  # 个股：价格/涨跌幅/PE/PB/市值/主力净流入
python3 scripts/a_stock_query.py sector [板块名]    # 板块近5日K线+区间涨跌幅（--days 可调）
python3 scripts/a_stock_query.py reports [代码]     # 券商研报：评级/机构/盈利预测
python3 scripts/a_stock_query.py margin [代码]      # 融资融券余额近5日
python3 scripts/a_stock_query.py chip [代码]        # 筹码分布（可选：pip install akshare）
python3 scripts/a_stock_query.py block [代码]       # 大宗交易（可选：pip install akshare）
```

### 网络检索兜底模板

```
[板块名] 板块 行情 主力资金流向          # A股板块行情/资金
[关键材料] 供需缺口 国产替代 扩产周期    # 供应链卡脖子
[板块] 政府工作报告 政策文件             # 政策催化
[公司名] 券商研报 评级 目标价           # 研报信号
[代码] 筹码分布 股东人数                # A股筹码信号
[代码] 大宗交易 折价率                  # A股大宗信号
TICKER 13F holdings / short interest   # 美股机构动向/空头比例
[港股代码] 南向资金 沽空比率            # 港股资金信号
```

### 港美股快速上手

```bash
python3 scripts/a_stock_query.py stock 00700    # 腾讯控股（HKD）
python3 scripts/a_stock_query.py stock NVDA     # 英伟达（USD）
python3 scripts/a_stock_query.py stock 台积电    # 支持中文名解析
python3 scripts/a_stock_query.py search 苹果     # 联想返回 A股/港股/美股候选
```

六步法分析流程与 A 股完全一致；差异在信号层——港美股用
13F/short interest（美股）、南向资金/沽空比率（港股）替代龙虎榜/两融/北向。

### 与六步法的对应关系

| 六步法步骤 | 用到的命令/检索 |
|-----------|---------------|
| 1 定位周期 | `sector` + 供需缺口检索 |
| 2 溯源供应链 | 供应链检索模板 |
| 3 四维信号卡 | `stock` + `reports` + `margin` |
| 4 真伪筛选 | 主营构成/竞争格局检索 |
| 5 多空确认 | `margin` + `chip`（可选）+ 资金流检索 |
| 6 输出报告 | 汇总以上，标注数据来源 |
